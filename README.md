# Nexus Orbit - React & Vite Landing Page

A modern, responsive, and minimalistic landing page built with React and Vite. This project was developed as part of Module 14 assignment to demonstrate component-based architecture and modern UI design.

## Features
- **Modern UI:** Dark theme implementation using raw CSS.
- **Component-Based:** Separated components for Header, Hero, About, and Footer.
- **Responsive Layout:** Flexbox-based alignment for clean presentation.

## Tech Stack
- React.js
- Vite
- CSS3
